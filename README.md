# Résumé Studio

[Open the browser demo on GitHub Pages](https://witchayada-t.github.io/Digital-Talent/)

The demo link works once GitHub Pages is enabled for this repository. In **Settings → Pages**, select **Deploy from a branch**, then **main** and **/ (root)**.

Choose a résumé template, enter CV details, and type a job title under an industry category. Check keyword coverage for the job posting and review the depth of each match. Use `| essential` or `| desirable` where the posting states a priority. The coverage score counts each listed skill once and the review list puts essential gaps first.

Choose Audit, Research, or Consulting and a career level, then click **Try an example** for a complete fictional CV. Add structured entries with dates and achievement bullets, and choose which CV section comes first. Choose **Download PDF** to save the current CV directly. **Print résumé** opens the browser’s print dialogue. CV text is processed in the browser.
